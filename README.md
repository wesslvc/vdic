# VDIC · 영단어 학습

강의 단위로 정리한 영단어를 학습하고, 오답만 모아서 다시 테스트할 수 있는 개인용 단어장 앱입니다.

## 기능

- **강의별 학습**: 23개 강의(챕터 01~07)로 묶인 단어를 플래시카드로 학습
- **오답노트**: 최근에 틀린 단어만 모아서 재시험, 맞히면 자동으로 제거
- **학습 기록**: 날짜별 학습량과 정답률, 최근 12주 히트맵
- **강의 재배정**: 자동 분류가 실제와 다르면 단어별로 강의를 직접 옮겨서 교정
- **백업/복원**: 설정 페이지에서 진행상황을 JSON으로 내보내기/불러오기

## 데이터 저장 방식

모든 학습 진행상황(정답/오답, 학습 기록, 강의 재배정)은 **브라우저 로컬 스토리지**에만 저장됩니다.
서버나 로그인 없이 바로 쓸 수 있지만, 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로
설정 페이지의 백업 내보내기/불러오기로 직접 옮겨야 합니다.

## 단어 데이터

`data/raw-vocab.txt`가 원본 노트이고, `scripts/build-words.mjs`가 이를 파싱해
`src/data/words.json`(23개 강의로 그룹핑된 실제 앱 데이터)을 생성합니다. 원본 노트를 수정한 뒤에는

```bash
node scripts/build-words.mjs
```

로 다시 생성하세요. 강의 경계는 실제 강의별 단어 수와 정확히 일치하지 않을 수 있어
(비슷한 단어가 한 항목으로 묶여 있어 실제 개수와 차이가 남) 앱 안에서 단어별로 강의를 재배정할 수 있습니다.

## 개발

